Quick Start

  1. Add the visual to your Power BI report from Microsoft AppSource.
  2. Drag a Location field (ISO country code, state abbreviation, or region name) into the Location role.
  3. Drag a numeric Value measure into the Value role.
  4. Select your Country / Region in the formatting pane → Map Settings.

Location Key Format

The Location field accepts any of the following formats:

  • ISO 3166-1 alpha-2: us, de, es
  • ISO 3166-1 alpha-3: usa, deu
  • Full country name: United States, Germany
  • US States: CA, TX, california

FAQ

My regions are not appearing on the map.
Check that your Location field values match the expected key format for the selected map. Try using ISO codes.

I upgraded to Pro but features are still locked.
Sign out of Power BI Desktop and sign back in to refresh your license status.

Can I use a custom TopoJSON file?
Yes — Pro subscribers can provide a URL to any publicly accessible TopoJSON file in the Pro Settings card.
