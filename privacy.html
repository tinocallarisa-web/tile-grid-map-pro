Privacy Policy

Product: Tile Grid Map Pro  ·  Publisher: TCViz  ·  Last updated: 2 August 2026

In short: this visual collects nothing. No telemetry, no analytics, no cookies. Your data never leaves your Power BI environment.

1. Data collection

Tile Grid Map Pro does not collect, transmit, store, or process any personal data outside your Power BI environment. All data processing occurs locally within your Power BI report session, in the browser or in Power BI Desktop.

2. Data processed locally

The visual processes only the data you explicitly add to its data roles: Latitude, Longitude, Value, Label and Tooltips. This data is used exclusively to determine which grid cell or polygon each coordinate falls into and to render the map within your report. It is never sent to any external server.

3. License verification

License status is verified through Microsoft's official IVisualLicenseManager API, which communicates with Microsoft AppSource infrastructure. No external or third-party license server is contacted. TCViz does not receive or store any personal information through this process.

4. Bundled map data

The built-in tile grid layouts for all 27 supported countries and regions are bundled inside the visual package itself. No external map tile servers or geographic APIs are contacted at runtime.

5. Custom TopoJSON — file upload (Pro)

When you drag a TopoJSON file onto the visual, the file is read locally in your browser using the standard FileReader API. No network request is made and the file is not uploaded anywhere.

The file contents are then stored inside your Power BI report file (.pbix) using the official Power BI persistProperties API, so that your boundaries are still present when you reopen the report. This data lives entirely within your own report file and is subject to your organisation's own Power BI data governance. TCViz has no access to it.

6. Custom TopoJSON — URL (Pro)

If you enter a URL in the Custom TopoJSON URL setting, the visual issues a single fetch() request to that address to download the boundary file. This request is initiated only by you, contains nothing beyond the URL itself, and is sent directly from your session to the host you specified. TCViz neither controls nor has access to that endpoint. This feature is entirely optional; the visual functions fully without it.

7. Cookies and tracking

This visual does not use cookies, local storage, session storage, or any tracking technologies whatsoever.

8. Third-party services

This visual does not integrate with any third-party analytics, advertising, or data-sharing services. It loads no external scripts at runtime.

9. Children's privacy

This visual is a business intelligence tool not directed at children. We do not knowingly collect data from individuals under 13 years of age.

10. Changes to this policy

If this policy changes, the "Last updated" date above will be revised. Any change affecting data handling will also be noted in the product changelog.

11. Contact
