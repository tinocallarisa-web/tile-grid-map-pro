Privacy Policy

Product: Tile Grid Map Pro  |  Publisher: TCViz  |  Last updated: 2025-01-01

1. Data Collection

Tile Grid Map Pro does not collect, transmit, store, or process any personal data outside your Power BI environment. All data processing occurs locally within your Power BI report session.

2. Data Processed Locally

The visual processes only the data you explicitly add to its data roles (Location, Value, Tooltips). This data is used exclusively to render the tile grid map within your report and is never sent to any external server.

3. License Verification

License status is verified through Microsoft's official IVisualLicenseManager API, which communicates with Microsoft AppSource infrastructure. TCViz does not receive or store any personal information through this process.

4. Bundled Map Data

Administrative boundary data (tile grid layouts) is bundled within the visual package itself. No external map tile servers or geographic APIs are contacted at runtime.

5. Custom TopoJSON (Pro Feature)

If you use the Custom TopoJSON URL feature, the visual will request data from the URL you provide. This URL is provided by you and processed within your Power BI session. TCViz has no access to this data.

6. Cookies & Tracking

This visual does not use cookies, local storage, or any tracking technologies.

7. Third-Party Services

This visual does not integrate with any third-party analytics, advertising, or data-sharing services.

8. Children's Privacy

This visual is a business intelligence tool not directed at children. We do not knowingly collect data from individuals under 13 years of age.
