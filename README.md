# Tile Grid Map Pro — TCViz

> Ship geo dashboards without a custom tile server. Bundled admin boundaries for 90+ countries rendered as square or hexagon tile grids.

[![AppSource](https://img.shields.io/badge/Microsoft_AppSource-Available-0078D4?logo=microsoft)](https://appsource.microsoft.com)
[![TCViz](https://img.shields.io/badge/Publisher-TCViz-2980b9)](https://tcviz.com)

## Features

| Feature | Free | Pro |
|---|---|---|
| World map (country-level tiles) | ✅ | ✅ |
| Square tile shape | ✅ | ✅ |
| Fixed sequential color scale | ✅ | ✅ |
| Tooltips + cross-filter | ✅ | ✅ |
| Hexagon tiles | ❌ | ✅ |
| 90+ country sub-region maps | ❌ | ✅ |
| Custom color scales | ❌ | ✅ |
| Bubble overlay | ❌ | ✅ |
| Custom TopoJSON import | ❌ | ✅ |

## Data Roles

- **Location** (Text) — ISO code, country name, state abbreviation
- **Value** (Measure) — numeric value to color tiles
- **Tooltips** (Measure, optional, Pro) — additional fields in tooltip

## Development

```bash
npm install
npm start        # dev server at https://localhost:8080
npm run build    # package .pbiviz
```
