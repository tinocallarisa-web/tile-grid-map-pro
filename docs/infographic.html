Tile Grid Map ProPOWER BI CUSTOM VISUAL · v1.1.0.0

Places every row on a tile of the country from its latitude and longitude and colours each tile by your measure. 27 countries and regions built in — or drop your own TopoJSON regions (Pro). No shapefiles, no GIS, no network requests.
1

Coordinates

Each row's latitude/longitude. Blank ones are skipped and counted "without coordinates".

2

Tile

The point goes to its land cell; coastal points snap to the nearest land cell within 3 cells. Farther rows count "outside the map".

3

Aggregate

Rows per tile combined: Auto follows the field well (measures use Sum). Blanks ignored, not zero.

4

Colour

Colour rules first, then the scale: sequential, quantile, diverging or categorical. No value → No Data Color.

Field wells

  • Latitude · Longitude — decimal degrees
  • Value — colours the tile
  • Size (Pro) — sizes it
  • Label · Tooltips · Category — names, hover fields, groups
