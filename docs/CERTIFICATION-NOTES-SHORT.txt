WHAT CHANGED IN 1.3.0.0
1. Legend range: click a legend entry or drag on the gradient; tiles outside dim.
   Map only: no filter, not persisted.
2. Target role (Pro): tile colour = (Value-Target)/|Target|, symmetric diverging scale.
3. Label Content: value, name, or name and value. Style template: Report theme + 6 Pro.
4. supportsHighlight: table + categorical in one mapping.
5. On-object formatting (onobjectutils): tiles, labels, legend. In format mode a click
   selects what to format and never filters.
6. 12 languages; on-canvas text also in the bundle.
7. Model format strings. Fixed: internal repaints sent extra rendering events; now
   exactly one start/finish per update.
8. ESLint 10, tools 7.2.1, API 5.11.1, audit 0.

TESTING FREE (no licence)
1. Sample .pbix: Latitude, Longitude, Value (Label, Tooltips, Category optional).
2. Map Settings: switch grids. Over 500 rows: "Showing the first 500 of N rows".
3. Legend: drag on the gradient, then click it to clear. Label Content: Name and value.
4. Click a bar in the other visual on the page: the map highlights, nothing is removed.
5. While EDITING, a style, Quantile/Diverging/Categorical, Circle/Hexagon, Size or Target
   draws under a "Pro preview" notice; Power BI shows the banner, then the Upgrade bar.
   Reading view: free result, no notice.
6. Click, Ctrl+click, right-click, keyboard. On-object: select tiles/labels/legend.

TESTING PRO (licence or trial)
All rows up to 30,000; Pro options apply with no notice; Custom TopoJSON: drop a file
(lon/lat WGS84, max 5 MB), it renders and persists on reopen.

PRIVACY: no network calls, telemetry or storage. privileges []. TopoJSON only by drag &
drop (FileReader). No innerHTML in own code. Interactions gated on hostCapabilities.allowInteractions.

LICENSING: getAvailableServicePlans. Pro when spIdentifier (full Service ID) ends with
".tile-grid-map-pro-tcviz" and state is Active or Warning. isLicenseUnsupportedEnv and
isLicenseInfoAvailable honoured.

FREE: maps, 500 rows, square tiles, Report theme, legend range, label content, rules,
tooltips, highlight, on-object.
PRO: 30,000 rows, 6 styles, Target, Size, circle/hexagon, quantile/diverging/categorical,
own colours, Custom TopoJSON.
